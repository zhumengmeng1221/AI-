快速接入

AIHub API 采用 RESTful 风格，所有请求通过 HTTP 发起，响应格式为 JSON。任务类接口采用异步模式：创建任务后返回 task_id，通过轮询查询结果。

Base URL

BASEhttps://your-domain.com

基本流程

1. 获取 API Key（在「API 密钥」页面创建）
2. 调用 /api/task/create 创建任务
3. 使用 /api/task/:id 轮询任务状态
4. 任务完成后获取结果 URL

创建任务示例

POST /api/task/create Content-Type: application/json { "type": "bgChange", "params": { "image": "https://example.com/product.jpg", "text": "海边沙滩背景" } } // 响应 { "taskId": "task_a8f3c2d1", "status": "pending", "type": "bgChange" }

查询任务示例

GET /api/task/task_a8f3c2d1 // 响应 - 进行中 { "taskId": "task_a8f3c2d1", "status": "running", "progress": 65 } // 响应 - 已完成 { "taskId": "task_a8f3c2d1", "status": "success", "results": [ { "url": "https://cdn.example.com/output1.jpg", "type": "image" } ] }
